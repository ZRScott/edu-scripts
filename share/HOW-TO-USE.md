# 🧩 Byte-Sized Toolbox — Teacher Quick-Start Guide

A catalog of **29 time-saving userscripts** for Connexus, Google Voice, Google Chat, Gmail, and Labster — with a point-and-click customizer. No coding needed.

---

## Step 1 — Install Tampermonkey (once, ~1 minute)

Userscripts run inside a free browser extension called **Tampermonkey**:

1. Open the **Chrome Web Store** (or Add-ons store in Firefox/Edge)
2. Search **"Tampermonkey"** → click **Add to Chrome** → confirm
3. A black square icon appears in your toolbar — done!

> 💡 If your school manages your Chromebook/extensions, you may need to ask your school Google Workspace admin to approve Tampermonkey first.

## Step 2 — Get a script from the Toolbox

1. Open the Toolbox page (your colleague will send you the file or a link)
2. Find a script — browse the category tabs or search (press `/`)
3. Click **⚙ Customize** to preview the code
   - Change any setting — colors, refresh intervals, messages, dataview IDs
   - The code preview updates live
4. Click **⬇ Install / Download .user.js**
5. Tampermonkey opens an install page → click **Install** ✅
   - (If nothing pops up: click the Tampermonkey icon → *Create a new script* → delete the template → paste the code you copied with **⧉ Copy Code** → Ctrl+S)

## Step 3 — Combine scripts into one bundle

Have several scripts for the same website? Bundle them into a single install:

1. Check the ☐ checkbox on each script's card
2. Click **⚡ Combine Selected Scripts**
3. Optionally rename the bundle, tweak any settings
4. **⬇ Install / Download .user.js** — one install, all the scripts, zero conflicts

## Good to know

| Thing | Answer |
|---|---|
| Where do edits save? | Customizations apply to the **exported copy** you download — your original stays stock |
| Script not running on a page? | Click the Tampermonkey icon while on that page to check it's enabled for that site |
| Remove a script? | Tampermonkey icon → Dashboard → 🗑 next to the script |
| Safe? | Everything is generated from our own team's scripts — inspect the full code in the preview before installing if you like |

*Questions? Ask whoever shared this with you — or check the script's `⚙ Customize` panel; most settings are self-explanatory.*
